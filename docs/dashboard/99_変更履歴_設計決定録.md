# ダッシュボード (dashboard) 変更履歴・設計決定録 (ADR)

## 2026-05-31 初版作成
* **変更内容**: ソースコードリーディングに基づく設計書の初版を作成
* **背景・理由 (Why)**: ダッシュボード機能（メインダッシュボード、記事トレーニング、YouTube集中視聴）の設計を文書化し、今後の保守・拡張に備える。既存のソースコード（`www/index.php`, `www/dashboard/*.php`, `private/apps/Dashboard/Service/*.php`, `migrations/done/add_dashboard_article_training.sql`）を通読し、実装に忠実な設計書を起こした。
* **見送った代替案**:
  - 記事トレーニングを独立アプリとして切り出す案: 現状はダッシュボードの一部として十分に機能しており、独立させるとナビゲーション導線が複雑になるため見送り。
  - RSSフィードの取得結果をDBに保存する案: キャッシュファイルで十分なTTL管理ができており、DB負荷を増やす必要がないため見送り。
