# Music（楽曲・リリース・アーティスト写真） UI設計書

## 1. 画面構成・レイアウト

### 楽曲トップ画面 (song_index.php)
- **構成要素**:
  - 共通サイドバー（`components/sidebar.php`）
  - ヘッダー（戻るボタン → Hinataポータル、楽曲アイコン、タイトル「楽曲」、管理者のみ「リリース管理」ボタン）
  - タブバー（「リリース」/「全曲」タブ切替 + グループフィルタ「すべて」/「日向坂46」/「けやき坂46」）
  - メインコンテンツ（リリース一覧カード or 全曲テーブル）

- **リリースタブ**: リリースカードを縦並び。各カードにはタイトル帯（種別バッジ・グループバッジ・タイトル・リリース日・収録曲数・表題センター名）と版別ジャケットサムネイル（w-36 h-36）を表示
- **全曲タブ**: リリース単位でグルーピング。帯部分にジャケットサムネイル（w-12 h-12）とリリース名。テーブルに `#`（トラック番号）、曲名、種別を表示。推しメンバーの参加曲は `bg-amber-50/60` でハイライトし、ハートアイコン付き

### 楽曲個別紹介画面 (song_detail.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻るボタン（遷移元に応じた動的URL）、楽曲アイコン、楽曲タイトル、管理者のみ「参加メンバー編集」ボタン）
  - セクションカード群（縦積み、`max-w-5xl`）:
    1. 基本情報（種別ラベル、タイトル、よみがな、収録リリースリンク）
    2. クレジット（作詞/作曲/編曲/振付/MV監督、該当項目のみ表示）
    3. 試聴（Apple Music / Spotify 埋め込み iframe。管理者は URL 編集フォーム付き）
    4. メイン動画（YouTube 埋め込み、アスペクト比 16:9）
    5. 関連動画（カテゴリ別、サムネイル+タイトル+説明。5件超はもっと見るボタン）
    6. 参加メンバー（期別一覧）
    7. フォーメーション（row_5 → row_1 の順で上から表示、各メンバーをアー写付きカードで配置。センターは `ring-2 ring-amber-400`。はみ出し時は全体を等倍縮小）
    8. ライブ披露（最新20件、イベント名+日付+アンコール区分）
    9. メモ
  - フッターリンク「楽曲一覧へ戻る」

### 参加メンバー編集画面 (song_member_edit.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻るボタン → 楽曲詳細、アイコン、タイトル「参加メンバー編集」）
  - 楽曲情報カード（楽曲名、リリース名）
  - タブ切替カード（「フォーメーション編集（D&D）」/「リスト編集」）
  - リスト編集パネル（非表示デフォルト）: メンバー追加フォーム + 編集テーブル（メンバー名/列/ポジション/センター/備考/削除）
  - フォーメーション編集パネル（表示デフォルト）: 左=メンバーパネル（期別グループ、縮小切替付き）、右=フォーメーション列（1-5列、ドロップゾーン）

### リリース詳細画面 (release_show.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻る → songs.php、ディスクアイコン、リリースタイトル）
  - 基本情報カード（メインジャケット w-16 h-16、種別・グループバッジ、タイトル、番号・発売日、説明）
  - 収録曲一覧カード（トラック番号・曲名・種別・ストリーミングアイコン）
  - 管理者専用セクション:
    - 楽曲順序編集（折りたたみ、トラック番号入力）
    - ストリーミングURL一括編集（折りたたみ、曲ごとにApple Music/Spotify入力欄、登録状態バッジ表示）
  - フッターリンク「リリース一覧へ戻る」

### リリース管理画面 (release_admin.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（ディスクアイコン、タイトル「リリース管理」、「ポータルへ戻る」ボタン）
  - 新規登録ボタン（`rounded-full shadow-lg`）
  - リリース一覧テーブル（種別/グループ/番号/タイトル/版・ジャケット/発売日/操作）
  - モーダルダイアログ（`max-w-4xl max-h-[90vh]`）: リリース登録・編集フォーム
    - 基本情報（種別セレクト、番号、グループ、タイトル、よみがな、発売日）
    - 版別ジャケット画像（type_a~type_d, normal。プレビュー + URL入力 + ファイルアップロード）
    - 収録曲（動的追加。曲名/よみがな/トラックNo./種別/作詞/作曲）
    - 説明テキストエリア

### リリース別アー写登録画面 (release_artist_photos.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻る → リリース詳細、画像アイコン、タイトル「アーティスト写真」）
  - リリース情報カード
  - メンバー別アー写フォーム（期別グループ化。各行: アバター w-10 h-10 + メンバー名 + URL入力 + ファイル選択ボタン。卒業生は区切り線の後に表示）
  - 保存ボタン + フッターリンク

### アー写一覧画面 (artist_photos_index.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻る → Hinataポータル、画像アイコン、タイトル「アーティスト写真」）
  - タブバー（「リリース別」/「メンバー別」）
  - リリース別タブ: リリースごとのカード（タイトル帯 + 期別グリッド `grid-cols-5 sm:grid-cols-7 md:grid-cols-9`）
  - メンバー別タブ: 期別セクション内にメンバーごとの行（メンバー名 + リリース横断のアー写グリッド）

## 2. 共通コンポーネントの利用
- `components/sidebar.php`: 共通サイドバー（全画面で使用）
- `components/head_favicon.php`: ファビコン（全画面で使用）
- `components/theme_from_session.php`: テーマカラー変数の初期化（全画面で使用）
- `Views/partials/member_modal.php`: メンバー詳細モーダル（楽曲詳細・アー写一覧で使用）

- `assets/js/hinata-member-modal.js`: メンバー詳細モーダルJS
- `assets/js/hinata-member-groups.js`: メンバーの期別グループ化ユーティリティ

## 3. 状態と表示制御 (State & Conditional Rendering)
- **タブ切替（楽曲トップ）**: `$_GET['tab']` が `songs` なら全曲タブ、それ以外はリリースタブ。CSS クラス `.active` でハイライト
- **グループフィルタ**: `$_GET['group']` で `hinatazaka46` / `hiragana_keyaki` にフィルタ。選択中は `bg-slate-800 text-white`
- **推しハイライト（全曲タブ）**: `$_SESSION['oshi']` のメンバーIDから `hn_song_members` を引き、該当曲の行を `bg-amber-50/60` + ハートアイコンで装飾
- **管理者ボタン**: `$user['role']` が `admin` または `hinata_admin` の場合のみ表示（リリース管理ボタン、参加メンバー編集ボタン、アー写リンク、楽曲順序編集、ストリーミング編集、ストリーミングURL管理の編集トグル）
- **フォーメーション表示条件**: 全メンバーの `position` が非NULLの場合のみ表示。一人でも NULL なら非表示
- **4列目・5列目（フォーメーション編集）**: メンバーが配置されているか、ユーザーが「追加」ボタンを押した場合のみ表示
- **卒業生表示（フォーメーション編集）**: チェックボックス `formationShowGraduates` で表示/非表示を切替
- **アー写一覧タブ**: `$_GET['tab']` が `members` ならメンバー別タブ、それ以外はリリース別タブ

## 4. スタイル・デザインルール
- **テーマカラー**: `$themePrimaryHex` を CSS 変数 `--hinata-theme` に設定。タブのアクティブ色、ボタン背景に使用
- **フォント**: `'Inter', 'Noto Sans JP', sans-serif`
- **カードUI**: `bg-white rounded-2xl border shadow-sm p-5`（セクションカード）
- **バッジ**: 種別バッジは `px-2 py-0.5 rounded text-[10px] font-black`。種別ごとに色分け（single=sky, album=indigo, digital=emerald, ep=amber, best=violet）
- **アーティスト写真の画像表示**: `object-cover object-top` を使用し、顔（頭部）が切れないようにする。フォーメーション表示・アー写一覧の両方でこのルールを適用
- **フォーメーション**: センターメンバーは `ring-2 ring-amber-400`（画像枠）+ `text-amber-700`（名前）。はみ出し時は `transform: scale()` で全体を等倍縮小
- **レスポンシブ**: サイドバーはデスクトップで固定幅240px、モバイルではハンバーガーメニューによるオーバーレイ表示
