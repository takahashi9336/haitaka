# Media（メディア管理） UI設計書

## 1. 画面構成・レイアウト

### 動画一覧画面 (media_list.php)
- **構成要素**:
  - 共通サイドバー (`components/sidebar.php`)
  - ヘッダー領域（モバイルメニューボタン、アイコン、タイトル「動画一覧」）
  - フィルタバー（プラットフォーム・カテゴリ・メンバー・世代・メディアタイプ選択、ソート切替）
  - メイン領域（レスポンシブグリッドによるビデオカード一覧）
  - 無限スクロールトリガー（IntersectionObserver によるスクロール検知）

- **ビデオカード構成**:
  - サムネイル（16:9 アスペクト比、`object-fit: cover`）
  - プラットフォームアイコンバッジ（左上）
  - メディアタイプバッジ（short/live の場合、右上）
  - タイトル（最大 2 行、省略表示）
  - カテゴリバッジ
  - アップロード日時

- **レスポンシブグリッド**:
  - モバイル: 1 列
  - タブレット (md): 2-3 列
  - デスクトップ (lg): 4-5 列

### メディア登録画面 (media_register.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー領域（アイコン、タイトル「メディア登録」、「動画一覧へ」リンク）
  - タブ切替（YouTube検索 / URL貼り付け / CSV/TSV インポート）
  - メイン領域（タブごとの入力フォームと結果プレビュー）

- **YouTube検索タブ**:
  - プリセットチャンネル選択ドロップダウン
  - キーワード検索入力フィールド
  - チャンネル動画一覧グリッド（サムネイル + タイトル + 登録済みバッジ）
  - ページネーション（前へ / 次へ）
  - 選択動画の一括登録ボタン

- **URL貼り付けタブ**:
  - URL テキストエリア（1 行 1 URL、最大 50 件）
  - カテゴリ選択ドロップダウン
  - 「取得」ボタン → oEmbed 結果プレビューリスト
  - プレビューカード（サムネイル・タイトル・プラットフォーム・重複ステータス）
  - 「登録」ボタン

- **CSV/TSV インポートタブ**:
  - テキストエリア（URL, タイトル, シングル番号, 公開日, カテゴリ）
  - デフォルトカテゴリ選択
  - プレビューボタン → 結果テーブル（ステータス色分け表示）
  - 一括保存ボタン

### 動画管理（統合）画面 (media_admin.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー領域（アイコン、タイトル「動画管理（統合）」、「ポータルへ戻る」リンク）
  - トースト通知（画面上部固定、操作結果表示）
  - タブ切替ボタン（メンバー紐付け / 楽曲紐付け / 設定）
  - 2 ペインレイアウト（左: 動画一覧、右: 編集パネル）

- **左ペイン（動画一覧セクション）**:
  - 検索フィールド（テキスト検索）
  - フィルタ（カテゴリ / プラットフォーム / メディアタイプ / 未紐付けのみ）
  - 動画リスト（行クリックで選択。選択行はテーマカラーの左ボーダーとハイライト背景）
  - 各行: サムネイル（小）+ タイトル + カテゴリバッジ + 日時

- **右ペイン（メンバー紐付けタブ）**:
  - 選択中動画の詳細表示（サムネイル・タイトル・プラットフォーム・説明文プレビュー）
  - メンバーチェックリスト（期別グループ化、メンバーカラー付き）
  - 「楽曲メンバーで設定」ボタン（楽曲紐付け済みの場合）
  - 保存ボタン

- **右ペイン（楽曲紐付けタブ）**:
  - 選択中動画の詳細表示
  - 現在の紐付け楽曲表示（リリース名 + 楽曲名 + 解除ボタン）
  - リリース選択ドロップダウン → 楽曲選択ドロップダウン
  - 紐付けボタン

- **右ペイン（設定タブ）**:
  - カテゴリ変更ドロップダウン
  - アップロード日時編集
  - メディアタイプ変更（video / short / live）
  - ハッシュタグ編集（タグ入力、一覧表示）
  - 削除ボタン（確認ダイアログ付き）
  - カテゴリ管理セクション（新規作成・名称変更）

## 2. 共通コンポーネントの利用
- `components/sidebar.php`: 全画面で左サイドバーを描画。モバイルはスライドインメニュー
- `components/head_favicon.php`: ファビコン設定
- `components/theme_from_session.php`: セッションからテーマカラーを取得し CSS 変数に反映
- `assets/js/hinata-member-groups.js`: メンバーの期別グループ化ヘルパー（動画管理画面で使用）

## 3. 状態と表示制御 (State & Conditional Rendering)

- **管理者機能の表示制御**:
  - `HinataAuth::requireHinataAdmin()` により、admin / hinata_admin ロール以外はメディア登録・動画管理画面にアクセスできない（ポータルにリダイレクト）
  - 動画一覧画面は全ログインユーザーがアクセス可能

- **YouTube API 設定状態**:
  - `YouTubeApiClient::isConfigured()` が false の場合、メディア登録画面の YouTube 検索タブで「APIキー未設定」メッセージを表示し、チャンネル検索・キーワード検索を無効化

- **動画管理 左ペイン → 右ペイン連動**:
  - 動画未選択時: 右ペインは「動画を選択してください」プレースホルダー
  - 動画選択時: 選択行を `.selected` クラスでハイライトし、右ペインに詳細・編集フォームを表示
  - タブ切替時: 右ペインの内容を切り替え（選択動画は維持）

- **重複ステータス表示**:
  - `New`: 青系バッジ (`status-ok`) — 新規登録対象
  - `Registered`: グレー系バッジ (`status-registered`) — 登録済み、スキップ対象
  - `Error`: 赤系バッジ (`status-error`) — エラー

- **ビデオカード hover エフェクト**:
  - `translateY(-2px)` + `box-shadow` で浮き上がりアニメーション

## 4. スタイル・デザインルール
- **テーマカラー**: CSS 変数 `--hinata-theme` にセッションの `$themePrimaryHex` を設定（デフォルト: `#0ea5e9` スカイブルー）
- **フォントファミリ**: `'Inter', 'Noto Sans JP', sans-serif`
- **Tailwind CSS**: CDN 版を使用（`https://cdn.tailwindcss.com`）
- **アイコン**: Font Awesome 6.5.1（CDN）
- **動画カード**: `bg-white border border-slate-200 rounded-xl shadow-sm`、hover で `translateY(-2px)` と `box-shadow: 0 8px 20px -4px rgba(0,0,0,0.1)`
- **サムネイルアスペクト比**: 16:9（`padding-bottom: 56.25%`）
- **サイドバー**: 幅 240px、モバイルは `position: fixed` でスライドイン
- **トースト通知**: 画面上部中央固定、背景 `#0f766e`、角丸フル（`rounded-full`）、3 秒後に自動消去
- **モバイル対応**: `@media (max-width: 768px)` でレイアウトを縦積みに切替。動画管理画面は上部に動画リスト（最大 45vh）、下部に編集パネル
