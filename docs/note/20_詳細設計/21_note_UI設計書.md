# メモ（Note） UI設計書

## 1. 画面構成・レイアウト

### メモ管理画面 (`www/note/index.php` → `private/apps/Note/Views/note_index.php`)

- **構成要素**:
  - 共通サイドバー（`private/components/sidebar.php`）
  - ヘッダー領域（電球アイコン、タイトル「メモ」、ダッシュボードへの戻りリンク）
  - 主タブバー（汎用メモ / リスト）
  - クイックメモ入力エリア（汎用メモタブ時のみ表示）
  - サブタブバー（アクティブ / アーカイブ）
  - メモカードグリッド（`#notesGrid`、カラムレイアウト）
  - リストセクション（`#listSection`、種別チップ + エントリ一覧）
  - メモ詳細モーダル（`#detailModal`）
  - リスト詳細モーダル（`#listDetailModal`）

### メモ詳細モーダル (`#detailModal`)

- **構成要素**:
  - タイトル入力フィールド（プレースホルダ: 「タイトル」）
  - 本文テキストエリア（自動伸長、プレースホルダ: 「メモを入力...」）
  - メタ情報（作成日時 / 更新日時）
  - アクションバー（ピン留め、背景色変更、アーカイブ/復元、削除、完了ボタン）
  - インラインカラーピッカー（10色の円形スウォッチ）

### リスト詳細モーダル (`#listDetailModal`)

- **構成要素**:
  - ヘッダー（タイトル「リスト編集」、メタ情報、閉じるボタン）
  - 動的フォーム領域（`#listDetailFields`、種別に応じて異なるフォームを生成）
  - アクションバー（背景色変更、ピン留め、アーカイブ/復元、削除、完了ボタン）
  - インラインカラーピッカー（10色の円形スウォッチ）

## 2. 共通コンポーネントの利用
- `private/components/sidebar.php`: 左サイドバーナビゲーション。折りたたみ可能で、モバイル時はスライドインメニュー
- `private/components/head_favicon.php`: ファビコン設定
- `private/components/theme_from_session.php`: セッションからテーマカラーを取得し、CSS変数 `--note-theme` に反映
- `/assets/js/core.js`: `App.post()` による非同期APIリクエストの共通関数

## 3. 状態と表示制御 (State & Conditional Rendering)

### 主タブの制御
- **汎用メモタブ選択時**: クイックメモ入力エリア・メモカードグリッドを表示、リストセクションを非表示
- **リストタブ選択時**: リストセクション（種別チップ + エントリ一覧 + 追加ボタン）を表示、クイックメモ・グリッドを非表示

### サブタブ（アクティブ/アーカイブ）の制御
- **アクティブ選択時**: アクティブメモ/リストを表示。カードにはピン留め・背景色変更・編集・アーカイブ・削除のアクションが表示される
- **アーカイブ選択時**: アーカイブ済みメモ/リストを表示。カードには復元・編集・削除のアクションが表示される

### クイックメモ入力エリアの制御
- **初期状態**: アクションボタン（追加ボタン）は `opacity-0` で非表示
- **フォーカス時**: アクションボタンが `opacity-100` でフェードイン
- **ブラー時**: タイトル・本文が空の場合のみアクションボタンをフェードアウト

### カードアクションの表示
- **デスクトップ**: カードホバー時にアクションアイコン群がフェードイン表示（`opacity` トランジション）
- **モバイル**: `focus-within` でタップ時にアクションが表示

### モーダルのアーカイブ/復元ボタン
- **アクティブビュー時**: アーカイブボタン表示、復元ボタン非表示
- **アーカイブビュー時**: 復元ボタン表示、アーカイブボタン非表示

### リスト種別別の表示形式
- **todo / generic_list**: リスト行形式（チェックボックス付き / 箇条書き）
- **question**: 2カラムグリッドのQ&Aカード（Solved / In Progress ステータスバッジ付き）
- **first_time**: タイムライン形式（左側にドット + ライン、右側にカード）
- **book**: スプリットレイアウト（左1/3がダークヘッダー、右2/3が情報パネル）
- **fun**: リスト行形式（ひとこと + 詳細）

### 空状態
- メモが0件の場合: 電球アイコンと「メモがありません」メッセージを中央表示
- リストが0件の場合: リストアイコンと「リストがありません」メッセージを中央表示

## 4. スタイル・デザインルール

### テーマカラー
- CSS変数 `--note-theme` にセッションの `$themePrimaryHex` を設定
- ボタン・タブ・ピン留めアイコンなどのアクセントカラーとして使用

### カラーパレット（背景色）
| 色名 | カラーコード | 用途 |
| :--- | :--- | :--- |
| 白 | `#ffffff` | デフォルト |
| イエロー | `#fef3c7` | 注意・注目 |
| レッド | `#fecaca` | 重要・警告 |
| ブルー | `#bfdbfe` | 情報・参考 |
| グリーン | `#bbf7d0` | 完了・OK |
| パープル | `#ddd6fe` | アイデア |
| ピンク | `#fbcfe8` | プライベート |
| オレンジ | `#fed7aa` | 進行中 |
| インディゴ | `#e0e7ff` | 学習 |
| グレー | `#f3f4f6` | アーカイブ候補 |

### カードレイアウト
- **グリッド**: CSS `column-count` によるマルチカラムレイアウト（`break-inside: avoid`）
  - `< 640px`: 1列
  - `>= 640px`: 2列
  - `>= 1024px`: 3列
  - `>= 1280px`: 4列
- **カードスタイル**: `bg-white rounded-lg border border-slate-100 shadow-sm`、ホバー時に `translateY(-2px)` + シャドウ強化

### モーダルアニメーション
- **開く**: クリック元カードの中心座標を起点とした拡大アニメーション（`modalExpandFromPoint`、0.4秒、cubic-bezier）
- **閉じる**: 起点への縮小アニメーション（`modalShrinkToPoint`、0.25秒）
- **背景**: フェードイン/フェードアウト

### フォント
- `Inter`（英数字）、`Noto Sans JP`（日本語）の組み合わせ

### サイドバー
- デスクトップ: 幅240px、折りたたみ時64px（CSS トランジション 0.3秒）
- モバイル: fixed配置、左からのスライドイン
