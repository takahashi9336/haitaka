# 管理画面 (admin) UI設計書

## 1. 画面構成・レイアウト

### 管理ポータル (portal.php)
- **構成要素**:
  - 共通サイドバー (`components/sidebar.php`)
  - ヘッダー: モバイルメニューボタン、アイコンバッジ (`fa-shield-halved`)、タイトル「管理画面」、「管理者専用」ラベル
  - カードグリッド: 管理機能10種のカード型リンク
- **レイアウト**: 2列 (モバイル) / 2列 (タブレット) / 3列 (PC) のグリッド。各カードは正方形 (モバイル: `aspect-square`) / 自動高さ (PC) でアイコン+タイトル+説明を表示
- **テーマ連動**: `sys_apps` の `theme_primary` / `theme_light` をセッションから取得し、カードアイコン背景・ホバー色に動的適用

### ユーザー管理 (users.php)
- **構成要素**:
  - 共通サイドバー
  - ユーザー一覧テーブル (id_name, ロール, 作成日, アクションボタン)
  - モーダル: ユーザー追加 / ロール変更 / パスワードリセット
- **操作方式**: 各操作はモーダル内フォームから外部 API (`/users_settings/api/`) へ JSON POST で送信

### アプリ管理 (apps.php)
- **構成要素**:
  - 共通サイドバー
  - ツリー構造テーブル: 親アプリ→子画面をインデント付きで表示。各行にアイコン・テーマ色プレビュー・説明
  - モーダル: 新規作成 / 編集。テーマ色プリセット選択 (Tailwind カラー名 or HEX 入力)
  - エラー表示: `$_SESSION['admin_error']` の内容をフラッシュ表示
- **操作方式**: フォーム POST → 同一 URL にリダイレクト (PRG パターン)

### ロール管理 (roles.php)
- **構成要素**:
  - 共通サイドバー
  - ロール一覧: PC ではテーブル表示、SP ではカード表示
  - モーダル: 新規作成 / 編集。`sidebar_mode = restricted` 選択時にアプリ割り当てチェックボックスが表示される
- **操作方式**: フォーム POST → 同一 URL にリダイレクト (PRG パターン)

### DB ビューワ (db_viewer.php)
- **構成要素**:
  - 共通サイドバー
  - テーブル選択: 左サイドまたは上部にテーブル名一覧 (GET パラメータで選択)
  - タブ切替: 「データ」「構造」「CREATE文」の3タブ
  - ページネーション: 50/100/250/500/all 件の切替 + ページ送り
  - アクションボタン: ダウンロード (CSV/SQL) / クリップボードコピー (JS で生成)
- **操作方式**: テーブル選択・ページ切替は GET パラメータ遷移。ダウンロード・コピーはブラウザ側 JS で処理

### DB 一括抽出 (db_export.php)
- **構成要素**:
  - 共通サイドバー
  - 4つのダウンロードボタン: 全CREATE文 (.sql) / スキーマMarkdown (.md) / スキーマJSON (.json) / 全データCSV ZIP (.zip)
- **操作方式**: 各ボタンは `?download=xxx` の GET リンク。クリックで即座にファイルダウンロード

### ガイド管理 一覧 (guides.php)
- **構成要素**:
  - 共通サイドバー
  - ガイド一覧テーブル/カード: guide_key、タイトル、ブロック数を表示
  - 新規作成ボタン → `?new=1` へ遷移
  - 各行に編集リンク (`?id=N`) と削除ボタン (POST)

### ガイド管理 編集 (guide_edit.php)
- **構成要素**:
  - 共通サイドバー
  - メタ情報フォーム: guide_key (テキスト)、title (テキスト)、app_key (テキスト)、show_on_first_visit (チェックボックス)
  - ブロックエディタ: テキストブロック / 画像ブロックの動的追加・並べ替え・削除。画像は API (`/admin/api/guide_image_upload.php`) でアップロード
  - 保存ボタン: ブロック配列を hidden input の `blocks_json` に JSON 化して POST 送信
- **操作方式**: フォーム POST → ガイド一覧にリダイレクト

### 対応管理 (improvement_list.php)
- **構成要素**:
  - 共通サイドバー
  - フィルタバー: ステータス選択 (未対応/対応済/見送り) + 画面名テキスト検索 (GET パラメータ)
  - 一覧テーブル/カード: 画面名・内容・ステータスバッジ・優先度・登録日を表示。並び順は未対応→対応済→見送り、各区分内は新しい順
  - インライン操作: 新規追加 (展開フォーム)、編集 (モーダル)、削除 (確認ダイアログ)
  - フラッシュメッセージ: 成功/エラーをセッション経由で表示

### 友達管理 (friends.php)
- **構成要素**:
  - 共通サイドバー
  - 友達ペア一覧テーブル: ユーザーA (id_name)、ユーザーB (id_name)、登録日
  - モーダル: 2つのユーザー選択ドロップダウンでペア登録
  - 各行に削除ボタン (POST)
  - フラッシュメッセージ: `$_SESSION['admin_success']` / `$_SESSION['admin_error']`

### グループ管理 (friend_groups.php)
- **構成要素**:
  - 共通サイドバー
  - グループ一覧テーブル: グループ名、メンバー数、作成日
  - モーダル: グループ作成 (グループ名 + メンバー複数選択チェックボックス)
  - インライン編集: `?edit=N` パラメータで編集フォームが一覧内に展開される。グループ名変更 + メンバー再選択
  - 各行に削除ボタン (POST)

### テキスト管理 (text_files.php)
- **構成要素**:
  - 共通サイドバー
  - SPA 的構成: 全操作を JavaScript + REST API で実行。画面遷移なし
  - 一覧表示: タイトル、拡張子バッジ、サイズ、更新日
  - 新規作成/編集フォーム: タイトル (テキスト)、拡張子 (txt/md/html ラジオ)、本文 (テキストエリア)
  - プレビュー: Markdown は `marked.js` でレンダリング、HTML はインラインプレビュー
  - 削除: 確認ダイアログ後に API DELETE

## 2. 共通コンポーネントの利用

| コンポーネント | パス | 役割 |
| :--- | :--- | :--- |
| サイドバー | `components/sidebar.php` | 全画面共通のナビゲーションサイドバー。アプリツリーを表示 |
| ファビコン | `components/head_favicon.php` | `<head>` 内のファビコンリンク |
| テーマ適用 | `components/theme_from_session.php` | `sys_apps` のテーマ色をセッションから取得し CSS 変数に適用 |
| 改善事項 FAB | `Admin/Views/partials/admin_utility_fab.php` | 右下の丸型 FAB。放射状にピル型ボタン展開 (改善事項追加 / 対応管理リンク) |

## 3. 状態と表示制御 (State & Conditional Rendering)

- **ポータルのテーマ色**:
  - `$themePrimary` が HEX 値の場合: インラインスタイルで直接色を適用
  - `$themePrimary` が Tailwind 名の場合: 対応する Tailwind クラス (`bg-{color}-50`, `text-{color}-600` 等) を適用
- **アプリ管理の削除制御**:
  - `is_system = 1`: 「システム固定のアプリは削除できません」エラー
  - `hasChildren() = true`: 「子画面があるアプリは先に子を削除してください」エラー
- **ロール管理のアプリ割り当て**:
  - `sidebar_mode = 'full'`: アプリ割り当てセクション非表示
  - `sidebar_mode = 'restricted'`: アプリ選択チェックボックスが表示される
- **対応管理のステータスバッジ**:
  - `pending`: 未対応 (警告色)
  - `done`: 対応済 (成功色)
  - `cancelled`: 見送り (グレー)
- **対応管理の resolved_at**:
  - ステータスを `done` に変更時: 自動で現在日時を設定
  - ステータスを `done` 以外に変更時: `NULL` にクリア
- **ガイド編集のモード制御**:
  - `?new=1`: 新規作成モード (空フォーム)
  - `?id=N`: 編集モード (既存データをプリフィル)
- **グループ管理の表示モード**:
  - `?edit=N` パラメータなし: 一覧のみ表示
  - `?edit=N` パラメータあり: 指定グループの編集フォームがインラインで展開
- **テキスト管理の拡張子制御**:
  - `html` 形式の保存時: 本文を Base64 エンコードして `content_b64` として送信

## 4. スタイル・デザインルール

- **テーマカラー**: 管理画面全体は `slate` 系 (`theme_primary = 'slate'`, `theme_light = 'slate-100'`) を使用。ヘッダーアイコンバッジは `bg-slate-700`
- **カード UI**: `bg-white border border-slate-200 rounded-xl shadow-sm` + ホバーで `translateY(-2px)` + 影の拡大
- **フォント**: `Inter` (英字) + `Noto Sans JP` (日本語)、Google Fonts CDN で読み込み
- **CSS フレームワーク**: Tailwind CSS (CDN 版 `cdn.tailwindcss.com`)
- **アイコン**: Font Awesome 6.5.1 (CDN)
- **レスポンシブ**: モバイルファーストの設計。サイドバーは 768px 以下でオーバーレイ表示 (`fixed` + `transform`)
- **FAB デザイン**: `w-16 h-16 rounded-full bg-slate-700`、クリックで CSS アニメーション付きのピル型ボタンが放射状に展開
