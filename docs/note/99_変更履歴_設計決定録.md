# メモ（Note） 変更履歴・設計決定録 (ADR)

## 2026-05-31 初版作成
* **変更内容**: メモ（Note）機能の設計書一式を初版として作成。機能概要書、機能一覧、画面遷移図、ER図、UI設計書、ドメイン定義書、処理詳細・I/O定義書の全7文書と本変更履歴を策定。
* **背景・理由 (Why)**: 既存実装のコード・マイグレーションファイルを精査し、設計意図と仕様を文書化することで、今後の保守・拡張を円滑にする。
* **見送った代替案**: 
  - Notionライクなリッチテキストエディタの導入 → 現時点ではプレーンテキスト + 自動改行で十分と判断。DB設計上は Markdown 対応を想定しているが、UIレンダリングは将来対応とした。
  - メモの論理削除（ゴミ箱機能）→ `nt_notes.status` に `trash` 値は定義済みだが、現時点のUIには導線を設けていない。将来的にゴミ箱画面を追加する可能性を残す。
  - リストエントリの `title` カラムの自動生成 → テーブル定義上は `title` カラムが存在するが、現在のコードでは `payload` 内のデータから動的に見出しを生成しているため、`title` カラムは未使用。将来的に一覧検索のパフォーマンス改善で活用する可能性がある。
