# Sense Lab（センスラボ） 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| スクラップ一覧画面 | `www/sense_lab/index.php` → `Views/index.php` | 本番スクラップをカード形式で一覧表示し、クイックスクラップをリスト形式で表示する。カテゴリ別集計も表示。 |
| スクラップ新規登録画面 | `www/sense_lab/new.php` → `Views/new.php` | 画像・タイトル・カテゴリ・理由1〜3を入力して本番スクラップを新規作成するフォーム画面。 |
| スクラップ詳細画面 | `www/sense_lab/show.php` → `Views/show.php` | 本番スクラップの画像・理由を詳細表示する。AIフィードバック欄（将来拡張用プレースホルダ）を含む。 |
| スクラップ編集画面 | `www/sense_lab/edit.php` → `Views/edit.php` | 既存の本番スクラップのタイトル・カテゴリ・画像・理由を編集するフォーム画面。 |
| クイックスクラップ編集画面 | `www/sense_lab/quick_edit.php` → `Views/quick_edit.php` | クイックスクラップのメモ・画像・カテゴリ・理由1〜3を後から編集するフォーム画面。 |
| クイックスクラップFABパネル | `Views/partials/sense_lab_utility_fab.php` | 全画面共通の右下フローティングボタン。展開するとメモ・画像・カテゴリ入力パネルが表示される。 |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| スクラップ一覧表示 | 画面 | ユーザーの本番スクラップ一覧とクイックスクラップ一覧を表示する。カテゴリフィルタ（GETパラメータ `category`）対応。 |
| スクラップ新規登録 | 画面/処理 | タイトル（必須）・カテゴリ・画像（任意）・理由1〜3（最低1つ必須）を入力して本番スクラップを登録する。 |
| スクラップ詳細表示 | 画面 | 指定IDの本番スクラップの画像・理由・カテゴリ・作成日時を表示する。 |
| スクラップ編集 | 画面/処理 | 既存の本番スクラップのタイトル・カテゴリ・画像・理由を更新する。画像は差し替え可能。 |
| スクラップ削除 | 処理 | 指定IDの本番スクラップをDBから削除し、関連画像ファイルも物理削除する。 |
| クイックスクラップ保存 | API (POST/JSON or FormData) | FABパネルからメモ（必須）・画像（任意）・カテゴリヒント・起点情報を非同期保存する。 |
| クイックスクラップ編集 | 画面/処理 | クイックスクラップのメモ・画像・カテゴリ・理由1〜3を後から更新する。 |
| 画像クライアント圧縮 | クライアント処理 | 2MBを超える画像をブラウザ側でJPEGにリサイズ・圧縮する（`sense_lab_image_compress.js`）。 |
| カテゴリ別集計 | 画面（一覧内） | 本番スクラップの件数をカテゴリ別に集計し、一覧画面上部に表示する。 |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| `sl_sense_entries` | 本番スクラップ | メインテーブル（CRUD全て） |
| `sl_sense_quick_entries` | クイックスクラップ | クイックメモ用テーブル（Create / Read / Update） |
| `sys_apps` | アプリ定義 | 参照のみ（`app_key = 'sense_lab'` で登録済み） |
