# ユーザー設定（users_settings） 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| 設定画面（パスワード変更） | `www/users_settings/index.php` → `private/apps/Settings/Views/index.php` | ログインユーザーが自身のパスワードを変更するための単画面 |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| パスワード変更画面表示 | 画面 | ログインユーザー向けのパスワード変更フォームを表示する（GET） |
| 自分のパスワード変更 | API (POST/JSON) | ログインユーザーが現在のパスワードを検証後、新しいパスワードへ更新する |
| ユーザー新規作成 | API (POST/JSON) | 管理者がユーザーID・初期パスワード・ロールを指定して新規ユーザーを作成する |
| パスワードリセット | API (POST/JSON) | 管理者が指定ユーザーのパスワードを強制的にリセットする |
| ロール変更 | API (POST/JSON) | 管理者が指定ユーザーのロールを変更し、対象ユーザーのセッションを無効化する |
| ヘルスチェック | API (GET) | サーバー死活確認用。固定文字列 "OK" を返す |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| sys_users | ユーザーマスタ | メインテーブル（Create: ユーザー作成 / Read: 認証・存在確認 / Update: パスワード更新・ロール更新） |
| sys_roles | ロールマスタ | 参照のみ（Read: ロールキーの存在確認） |
| sys_sessions | セッション | Delete: ロール変更時に対象ユーザーのセッションを無効化 |
