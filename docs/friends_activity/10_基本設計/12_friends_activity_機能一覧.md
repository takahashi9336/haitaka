# フレンズアクティビティ (FriendsActivity) 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| 友人の視聴一覧画面 | `www/friends_activity.php` → `private/apps/FriendsActivity/Views/activity.php` | 友人・グループメンバーの視聴済み作品をアニメ・映画・ドラマ横断で一覧表示する |
| 友達管理画面（管理者） | `www/admin/friends.php` → `private/apps/Admin/Views/friends.php` | 管理者が1対1の友達ペアを登録・削除する |
| グループ管理画面（管理者） | `www/admin/friend_groups.php` → `private/apps/Admin/Views/friend_groups.php` | 管理者がユーザーグループを作成・編集・削除し、メンバーを管理する |
| 映画ダッシュボード（埋め込み） | `private/apps/Movie/Views/movie_dashboard.php` | 映画ダッシュボード内の「友人の視聴」セクションに映画のみ最大12件を表示 |
| アニメダッシュボード（埋め込み） | `private/apps/Anime/Views/anime_dashboard.php` | アニメダッシュボード内の「友人が視聴したアニメ」セクションにアニメのみ最大12件を表示 |
| ドラマダッシュボード（埋め込み） | `private/apps/Drama/Views/drama_dashboard.php` | ドラマダッシュボード内の「友人が視聴したドラマ」セクションにドラマのみ最大12件を表示 |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| 友人視聴一覧表示 | 画面 | 閲覧可能ユーザーの視聴済み作品を3ジャンル横断で一覧表示（種別/ユーザーフィルタ対応） |
| 種別フィルタリング | 画面 | GETパラメータ `filter` でアニメ/映画/ドラマを絞り込み表示 |
| ユーザーフィルタリング | 画面 | GETパラメータ `user_id` で特定の友人の視聴履歴のみ表示 |
| 作品プレビュー表示 | 画面/JS | カード押下でアニメ/映画/ドラマ各アプリのプレビューモーダルを呼び出す |
| アニメをリストに追加 | API（非同期） | POST `/anime/api/set_status.php` を呼び出し、見たい/見てる/見たに追加 |
| 映画をリストに追加 | API（非同期） | POST `/movie/api/add.php` を呼び出し、見たい/見たに追加 |
| ドラマをリストに追加 | API（非同期） | POST `/drama/api/add.php` を呼び出し、見たい/見てる/見たに追加 |
| 友達ペア登録（管理者） | 画面/処理 | 管理者が2人のユーザーを友達ペアとして登録する |
| 友達ペア削除（管理者） | 画面/処理 | 管理者が既存の友達ペアを削除する |
| グループ作成（管理者） | 画面/処理 | 管理者がユーザーグループを新規作成し、メンバーを追加する |
| グループ編集（管理者） | 画面/処理 | 管理者がグループ名を変更し、メンバー構成を更新する |
| グループ削除（管理者） | 画面/処理 | 管理者がグループを削除する（CASCADEでメンバーも削除） |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| sys_user_friends | 友達ペア | 管理者による CRUD（本機能は参照のみ） |
| sys_user_groups | ユーザーグループ | 管理者による CRUD（本機能は参照のみ） |
| sys_user_group_members | グループメンバー | 管理者による CRUD（本機能は参照のみ） |
| sys_users | ユーザー | 参照（id_name の取得） |
| an_user_works | アニメ視聴ステータス | 参照（友人の視聴済み作品取得）、作品追加時に更新 |
| an_works | アニメ作品マスタ | 参照（作品タイトル・画像URL取得） |
| mv_user_movies | 映画視聴ステータス | 参照（友人の視聴済み作品取得）、作品追加時に更新 |
| mv_movies | 映画作品マスタ | 参照（作品タイトル・ポスター・TMDB ID取得） |
| dr_user_series | ドラマ視聴ステータス | 参照（友人の視聴済み作品取得）、作品追加時に更新 |
| dr_series | ドラマ作品マスタ | 参照（作品タイトル・ポスター・TMDB ID取得） |
