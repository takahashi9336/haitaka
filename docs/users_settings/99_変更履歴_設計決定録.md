# ユーザー設定（users_settings） 変更履歴・設計決定録 (ADR)

## [2026-05-31] 初版作成
* **変更内容**: ソースコードリーディングに基づく設計書の初版を作成
* **背景・理由 (Why)**: 既存実装の仕様を設計書として明文化し、保守性・可読性を向上させるため。`www/users_settings/` 配下の全エントリポイント、`private/apps/Settings/Controller/SettingsController.php`、関連する `Core\UserModel`・`Core\RoleModel`・`Core\SessionManager`・`Core\Auth` の実装を精査した。
* **見送った代替案**:
  - 管理者向け API を `/admin/api/` 配下に配置する案 -- 既に `/users_settings/api/` に統一されておりリファクタリングコストに見合わないため見送り。管理画面（Admin アプリ）は UI のみを担当し、API は Settings アプリ側に集約する現行設計を維持する。
  - ユーザー作成時に admin ロールも選択可能にする案 -- セキュリティリスクが高いため、コード上で `Admin作成禁止` のバリデーションを維持する設計とした。
