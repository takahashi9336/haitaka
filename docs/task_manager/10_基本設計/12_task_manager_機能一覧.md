# タスク管理 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| タスク管理メイン画面 | `www/task_manager/index.php` | エントリポイント。TaskController::index() を呼び出す |
| タスク管理ビュー | `private/apps/TaskManager/Views/index.php` | リスト/ボード/ガント/カレンダーの4モードを持つSPA的な単一画面 |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| タスク一覧表示 | 画面 | 全タスクをカテゴリ情報付きで取得し、リストビューで描画する |
| リストビュー | 画面/JS | タスクを優先度順・カテゴリ順でソート表示。検索・フィルタ機能付き |
| ボードビュー (カンバン) | 画面/JS | 未着手/進行中/保留/完了の4列にタスクを配置。SortableJSによるドラッグ&ドロップでステータス変更 |
| ガントチャートビュー | 画面/JS | 開始日〜期日を横軸の日付バーで表示。当日ハイライト付き |
| カレンダービュー | 画面/JS | FullCalendarで月別にタスク期日を表示。日向坂イベントの重畳表示トグル付き |
| 統計サマリ表示 | 画面/JS | 全タスクのステータス別件数・期限超過件数・完了率プログレスバーを表示 |
| タスク検索 | 画面/JS | タイトル・説明・カテゴリ名でのインクリメンタルサーチ |
| カテゴリフィルタ | 画面/JS | カテゴリ別・優先度別のプルダウンフィルタ |
| 完了済み表示トグル | 画面/JS | 完了タスクの表示/非表示を切り替え |
| 日向坂イベント表示トグル | 画面/JS | カレンダーモード時、日向坂イベントの表示/非表示を切り替え |
| クイック追加 | 画面/API | ヘッダーフォームからタスクを即時登録（POST → api/save.php） |
| タスク詳細/編集モーダル | 画面/API | スライドパネルでタスクの全項目を表示・編集（POST → api/update.php） |
| タスク新規作成 | API (POST) | `api/save.php` 経由で JSON リクエストを受け取り、新規タスクをDBに保存 |
| タスク更新 | API (POST) | `api/update.php` 経由で既存タスクのフィールドまたはステータスのみを更新 |
| タスク削除 | API (POST) | `api/delete.php` 経由で指定IDのタスクを削除 |
| ステータス変更 (チェックボックス) | 画面/API | リストビューのチェックボックスで todo/done をトグル |
| ステータス変更 (ドラッグ&ドロップ) | 画面/API | ボードビューでカード移動時にステータスを自動更新 |
| カテゴリ自動作成 | API内部処理 | タスク保存時にカテゴリ名が新規の場合、tm_categoriesにレコードを自動作成 |
| URLパラメータによるタスク自動オープン | 画面/JS | `?task_id=N` でアクセス時、該当タスクの詳細モーダルを自動表示 |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| tm_tasks | タスク | メインテーブル (CRUD すべて) |
| tm_categories | カテゴリ | カテゴリマスタ (CR: 作成・参照。色の更新あり) |
| hn_events | 日向坂イベント | カレンダービューで今後のイベントを参照 (Read のみ) |
