# タスク管理 画面遷移図

## 1. 画面遷移フロー

タスク管理は単一画面（SPA的構成）で完結する。画面内のモード切替（タブ）とモーダルにより操作が行われる。

```mermaid
stateDiagram-v2
    [*] --> リストビュー : /task_manager/ アクセス
    
    state メイン画面 {
        リストビュー --> ボードビュー : ボードタブ押下
        リストビュー --> ガントチャート : ガントチャートタブ押下
        リストビュー --> カレンダー : カレンダータブ押下
        
        ボードビュー --> リストビュー : リストタブ押下
        ボードビュー --> ガントチャート : ガントチャートタブ押下
        ボードビュー --> カレンダー : カレンダータブ押下
        
        ガントチャート --> リストビュー : リストタブ押下
        ガントチャート --> ボードビュー : ボードタブ押下
        ガントチャート --> カレンダー : カレンダータブ押下
        
        カレンダー --> リストビュー : リストタブ押下
        カレンダー --> ボードビュー : ボードタブ押下
        カレンダー --> ガントチャート : ガントチャートタブ押下
    }

    リストビュー --> 詳細編集モーダル : タスク行クリック
    ボードビュー --> 詳細編集モーダル : カードクリック
    ガントチャート --> 詳細編集モーダル : バー行クリック
    カレンダー --> 詳細編集モーダル : イベントクリック
    
    詳細編集モーダル --> リストビュー : 保存完了/キャンセル/Escape
```

## 2. 操作フロー詳細

```mermaid
flowchart LR
    A[メイン画面表示] --> B[クイック追加フォーム]
    B -->|POST api/save.php| C[タスク作成成功]
    C --> D[リスト再描画 + 統計更新]
    
    A --> E[タスククリック]
    E --> F[詳細編集モーダル表示]
    F -->|POST api/update.php| G[タスク更新成功]
    F -->|POST api/delete.php| H[タスク削除成功]
    G --> D
    H --> D
    
    A --> I[チェックボックス操作]
    I -->|POST api/update.php| J[ステータス変更]
    J --> D
    
    A --> K[ボードでドラッグ&ドロップ]
    K -->|POST api/update.php| L[ステータス変更]
    L --> D
```

## 3. URL パラメータ遷移

| パラメータ | 動作 |
| :--- | :--- |
| `/task_manager/` | 通常のリストビュー表示 |
| `/task_manager/?task_id=N` | 初期表示後に該当タスクの詳細モーダルを自動オープン。オープン後URLを `/task_manager/` にリプレース |
