# ダッシュボード (dashboard) 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| メインダッシュボード | `www/index.php` | ログイン後のポータルトップ。日付表示、気になる記事（RSSフィード）、次の日向坂イベント、タスク一覧、各機能へのナビゲーションカードを集約表示する |
| 記事トレーニング画面 | `www/dashboard/article_training.php` | 記事URLを入力し、その記事に対する「ほめポイント」3つと「ツッコミポイント」3つを書き出すトレーニング画面。カウントダウンタイマー付き |
| 記事トレーニング履歴画面 | `www/dashboard/article_training_history.php` | 過去に実施した記事トレーニングの一覧を表示し、各記事のトレーニング画面へ遷移できる |
| YouTube集中視聴画面 | `www/dashboard/youtube_focus.php` | 環境変数で指定したYouTubeチャンネルの最新動画を一覧表示する。投稿日時順とチャンネル別の2つの表示モードを持つ |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| ダッシュボード表示 | 画面 | 当日の日付、未完了タスク上位5件、次の日向坂イベント、推しメンバー誕生日（30日以内）、RSSフィード記事、各機能ナビカードを一画面に集約表示する |
| RSSフィード取得 | 画面内処理 | Google News RSS（好奇心ブースト10テーマ + AI関連）とBlogger RSS（パレオな男）を取得し、1時間キャッシュして表示する |
| 好奇心ブースト記事選択 | 画面内処理 | 同一ユーザー・同一日（JST）で決定的に1記事を選択する。直近表示済みURLを除外し、テーマを日替わりで変更する |
| 記事トレーニングURL入力 | 画面 | 記事URLとタイトル（任意）を入力してトレーニングを開始する。URLはhttp/httpsのみ、500文字以内でバリデーションする |
| 記事トレーニング実施 | 画面 | 記事を読み、ほめポイント3つとツッコミポイント3つをテキストエリアに記入する。カウントダウンタイマーで時間管理を行う |
| 記事トレーニング保存 | API (JSON) | ほめポイント3つとツッコミポイント3つをJSON形式でPOSTし、DBに保存する（INSERT or UPDATE） |
| 記事トレーニング履歴表示 | 画面 | ユーザーの記事トレーニング履歴を最新50件まで一覧表示する |
| YouTube集中視聴表示 | 画面 | 環境変数で指定したチャンネルの最新動画を取得し、投稿日時順またはチャンネル別で表示する。30分キャッシュ |
| YouTube動画再生 | 画面内処理 | 動画カードクリックで共通video_modalコンポーネントを使用してモーダル再生する |
| カウントアップアニメーション | 画面内処理 | ナビゲーションカードの数値をカウントアップアニメーションで表示する（600ms、easeOutCubic） |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| dashboard_article_training | 記事トレーニング | メインテーブル (CRUD: 作成=INSERT、更新=ON DUPLICATE KEY UPDATE、参照=SELECT)。ユーザーごとの記事URL単位でほめ/ツッコミを保存 |
| sys_users | システムユーザー | 参照のみ。認証・ユーザーID取得に使用 |
| sys_apps | システムアプリ | 参照のみ。サイドバー表示・テーマ解決に使用（`app_key = 'dashboard'`） |
