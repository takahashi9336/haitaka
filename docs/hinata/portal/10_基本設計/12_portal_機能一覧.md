# ポータル（Portal） 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| ポータルダッシュボード | `www/hinata/index.php` -> `HinataController::portal()` -> `Views/portal.php` | 各サブドメインのデータを集約表示するメイン画面 |
| ポータル情報管理 | `www/hinata/portal_info_admin.php` -> `PortalInfoController::admin()` -> `Views/portal_info_admin.php` | トピック・お知らせ・応募締め切りの管理画面（管理者専用） |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| ポータル表示 | 画面 | ログインユーザーに対し、推しサマリ・TOPICS・次のイベント・ミーグリ予定・最新リリース・最新ブログ・YouTube/TikTokカルーセル・SNSリンク・アプリ導線等を一画面に集約表示 |
| 推しメンバー切り替え | 画面（JS） | 最推し/2推し/3推しをクリックで切り替え、メイン推しエリアの情報を動的に更新（APIコール不要、初期データをJSON埋め込み） |
| ポータル内検索 | 画面（JS） | ヘッダーの検索ボックスで画面内のカード/リンクをキーワードフィルタ |
| トピック登録/更新 | API (JSON) | 管理画面からトピックを新規作成または更新する |
| お知らせ登録/更新 | API (JSON) | 管理画面からお知らせを新規作成または更新する |
| トピック画像アップロード | API (multipart) | トピック用画像をアップロードし保存パスを返却する |
| お知らせ画像アップロード | API (multipart) | お知らせ用画像をアップロードし保存パスを返却する |
| 収録曲アコーディオン展開 | 画面（JS） | 最新リリースセクションで収録曲リストをアコーディオンで展開/折りたたみ |
| ストリーミング再生 | 画面（JS） | 収録曲のApple Music / Spotify埋め込みプレーヤーをインライン展開 |
| 動画モーダル再生 | 画面（JS） | YouTube/TikTokカルーセルのカードクリックで動画モーダルを開く |
