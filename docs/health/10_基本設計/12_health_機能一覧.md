# Health（ヘルスケア/健康管理） 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| Healthポータル | `www/health/index.php` → `private/apps/Health/Views/portal.php` | Health機能群のトップ画面。食材ストック・トレーニングメニュー・実施履歴・献立（準備中）へのカード型リンクを提供する |
| 食材ストック | `www/health/kitchen_stock.php` → `private/apps/Health/Views/kitchen_stock.php` | 冷蔵庫/冷凍庫の食材在庫を一覧・追加・編集・削除する画面。グループフィルタ、Markdown形式コピー機能付き |
| トレーニングメニュー | `www/health/training_menu.php` → `private/apps/Health/Views/training_menu.php` | トレーニング種目（名前・回数・時間）を登録・編集・削除する画面。HIIT完了ボタンと参照動画の埋め込みを含む |
| トレーニング実施履歴 | `www/health/training_history.php` → `private/apps/Health/Views/training_history.php` | トレーニングの実施記録を閲覧・追加・削除する画面。ヒートマップ（アクティビティ）と統計情報を表示する |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| ポータル表示 | 画面 | Health配下の各機能カードを表示する。未実装機能は `disabled` 状態で表示 |
| 食材ストック一覧取得 | API (POST → JSON) | ログインユーザーの全食材ストックを取得する。`purchased_date` 降順ソート |
| 食材ストック登録 | API (POST → JSON) | 食材名・グループ・数量・購入日・冷凍フラグを指定して新規登録する |
| 食材ストック更新 | API (POST → JSON) | 既存食材の任意フィールドをパッチ更新する（名前・数量・購入日・冷凍フラグ・グループ） |
| 食材ストック削除 | API (POST → JSON) | 指定IDの食材ストックを削除する |
| 食材ストックMarkdownコピー | 画面内JS | 在庫一覧をMarkdownテーブル形式でクリップボードにコピーする |
| トレーニングメニュー一覧取得 | API (POST → JSON) | ログインユーザーの全トレーニングメニューを取得する。`id` 昇順ソート |
| トレーニングメニュー登録 | API (POST → JSON) | メニュー名・回数・1セットあたりの時間（秒）を指定して新規登録する |
| トレーニングメニュー更新 | API (POST → JSON) | 既存メニューの任意フィールドをパッチ更新する（名前・回数・時間） |
| トレーニングメニュー削除 | API (POST → JSON) | 指定IDのトレーニングメニューを削除する |
| HIIT完了（一括記録） | API (POST → JSON) | 全登録メニューを1つのHIITセッションとしてまとめて実施履歴に記録する |
| トレーニング実施履歴一覧取得 | API (POST/GET → JSON) | 指定期間の実施履歴を取得する。デフォルトは過去3ヶ月分、最大500件 |
| トレーニング実施履歴登録（個別） | API (POST → JSON) | メニューを指定して個別の実施記録を作成する。回数・時間のオーバーライド可能 |
| トレーニング実施履歴登録（HIIT） | API (POST → JSON) | 指定日のHIITセッションを後から追加する。現在の登録メニューをスナップショット保存 |
| トレーニング実施履歴削除 | API (POST → JSON) | 指定IDの実施履歴を削除する |
| ヒートマップ描画 | 画面内JS | 直近6ヶ月分の実施履歴をGitHub風ヒートマップで可視化する。統計（連続日数・月間回数等）も表示 |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| `hl_kitchen_stock_items` | 食材ストック | 食材在庫のメインテーブル (CRUD全て) |
| `hl_training_menu_items` | トレーニングメニュー | トレーニング種目のマスタテーブル (CRUD全て) |

| `sys_role_apps` | ロール別アプリ権限 | ロールに応じたアクセス制御 (R: 参照のみ) |
