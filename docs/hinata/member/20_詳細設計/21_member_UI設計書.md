# メンバー (Member) UI設計書

## 1. 画面構成・レイアウト

### メンバー帳 (members.php)

- **構成要素**:
  - 共通サイドバー (`components/sidebar.php`)
  - ヘッダー: 戻るボタン (`/hinata/index.php`)、アイコン、タイトル「メンバー帳」、管理ボタン (admin/hinata_admin のみ)
  - フィルタバー: 期生フィルタ (全員/1期-5期)、ソートセレクト (期生順/名前順/生年月日順/身長順)、昇順降順切替、カード/リスト切替、卒業メンバー表示切替
  - メインコンテンツ:
    - カード表示 (`#memberGrid`): グリッドレイアウト (2-5列レスポンシブ)。期生順の場合はグループヘッダー付き
    - リスト表示 (`#memberList`): テーブル形式 (SNSリンク・画像・名前・期・サイリウム)
  - メンバー詳細モーダル (`partials/member_modal.php`)

- **カード表示の特徴**:
  - アスペクト比 3:4。画像はカード全面に `object-cover` で表示
  - 上部にサイリウムカラーのグラデーションストリップ (1.5px)
  - 右上: お気に入りバッジ (最推し=王冠/2推し=ハート/3推し=ハート/気になる=星)
  - 左上: 卒業バッジ (非現役メンバーのみ)
  - 下部: サイリウムカラーグラデーション帯 + 期生バッジ + メンバー名
  - オーバーレイ: 上から下への黒グラデーション (テキスト可読性確保)

- **リスト表示の特徴**:
  - SNSアイコン (ブログ/Instagram/YouTube PV) のアクティブ/非アクティブ表示
  - サムネイル画像 (40x40, rounded-xl)
  - サイリウムカラーチップ (color1 x color2)

### メンバー管理 (member_admin.php)

- **構成要素**:
  - 共通サイドバー
  - ヘッダー: アイコン、タイトル「メンバー管理」、戻るボタン (`/hinata/members.php`)
  - タブ切替: 「詳細編集」/「一覧編集」
  - 詳細編集タブ:
    - 左カラム (2/3幅): メンバー編集フォーム + 個人活動セクション
    - 右カラム (1/3幅): メンバー選択リスト (期別グルーピング)
  - 一覧編集タブ:
    - 全メンバーのインラインテーブル (横スクロール対応、ID/名前列はスティッキー)
    - 各行の個別保存ボタン + 一括保存ボタン

- **詳細編集フォーム**:
  - 画像スロット (最大5枚): プレビュー付きファイルアップロード
  - 基本情報: 名前、かな、血液型、身長、期生 (0=ポカ, 1-5)、生年月日、出身地
  - テキストエリア: メンバー情報
  - サイリウムカラー: カラーマスタからの選択 (2色)
  - SNS/動画: YouTube URL、ブログ URL、Instagram URL、Twitter URL
  - 状態: 現役/卒業の選択

- **個人活動セクション**:
  - 活動一覧: カテゴリアイコン + タイトル + URL + 編集/削除ボタン (hover表示)
  - 追加/編集フォーム: カテゴリ選択、活動名、説明、URL、ボタンラベル、サムネ画像、開始/終了日、表示状態

### メンバー個別ページ (oshi_member.php / member.php)

- **構成要素**:
  - 共通サイドバー
  - ヘッダー: 戻るボタン、メンバー名、推しレベルバッジ
  - ヒーローエリア (h-56/h-72): ぼかし背景画像、プロフィール画像 (カスタム変更対応)、メンバー基本情報、SNSリンクボタン
  - コンテンツセクション (max-w-5xl):
    1. タイムライン: ブログ・ニュース・スケジュール・イベント・動画を日付降順で統合表示
    2. 個人活動: カテゴリバッジ付きカードグリッド (2列)
    3. 最新ブログ: 横スクロールカルーセル (ポートレート型カード、3:4比率)
    4. ニュース + スケジュール: 2カラムグリッド
    5. 動画: タブ切替 (ソロ/YouTube/Instagram/TikTok) + 横スクロールカルーセル
    6. 参加楽曲: リスト形式 (Apple Music/Spotify ミニプレーヤー対応)
    7. イベント: 今後の予定 + 折りたたみ式の過去イベント
    8. マイフォト: グリッド表示 (3-5列) + ドラッグ&ドロップアップロード (推し設定時のみ)
    9. ミーグリネタ: インライン追加 + チェックボックスでステータス切替

- **ヒーローエリアの画像表示**:
  - ユーザー設定のプロフィール画像 (`hn_user_member_profiles`) を優先
  - 未設定時は管理者プリセット画像 (`hn_member_images` の先頭)
  - プロフィール画像はホバーで「変更」ボタンが表示され、ファイル選択で即座にアップロード

### 推し設定 (oshi_settings.php)

- **構成要素**:
  - 共通サイドバー
  - ヘッダー: 戻るボタン (`/hinata/`)、アイコン、タイトル「推し設定」
  - 推しスロット表示: 3カラムグリッド (最推し/2推し/3推し)
    - 設定済み: メンバー画像 + 名前 + 期生 + 解除ボタン
    - 未設定: プラスアイコン + 「下のメンバーから選択」
  - メンバー一覧: 期別グループ + グリッドカード (4-8列)
    - 各カードにレベル選択セレクト (--/最推し/2推し/3推し/気になる)
    - 設定済みメンバーにはリングカラーとラベルバッジ

### ペンライトカラー表 (penlight.php)

- **構成要素**:
  - 共通サイドバー
  - ヘッダー: 戻るボタン、アイコン、タイトル「ペンライトカラー表」、「初心者向け」ラベル
  - フィルタバー: 期生フィルタ (全員/1期-5期)、卒業メンバー切替、名前検索
  - 公式ペンライト発光色画像セクション (1-15番)
  - メンバーカラーテーブル: 氏名 + カラー1チップ + カラー2チップ
  - アー写拡大モーダル: 最新シングルのアー写がある場合、クリックで拡大表示

- **アー写表示の注意点**: メンバー画像には `object-cover object-top` を適用し、頭が切れないようにする

## 3. 状態と表示制御 (State & Conditional Rendering)

- **メンバー帳のフィルタ/ソート**:
  - `currentGen`: 全員 / 1-5 期生のフィルタ
  - `viewMode`: カード / リスト の切り替え
  - `showGraduates`: 卒業メンバーの表示/非表示
  - `currentSortOrder`: 期生順 / 名前順 / 生年月日順 / 身長順
  - `isAscending`: 昇順 / 降順

- **メンバー管理の詳細編集フォーム**:
  - 初期状態: `opacity-30 pointer-events-none`（メンバー未選択）
  - メンバー選択後: フォーム活性化 + 個人活動セクション活性化

- **メンバー個別ページの条件分岐**:
  - `$oshiLevel > 0`: マイフォトセクション表示、戻り先がポータル
  - `$oshiLevel === 9`: 最推しバッジ（王冠）をプロフィール画像右上に表示
  - 動画タブ: ソロ/YouTube/Instagram/TikTok の各タブはデータが存在する場合のみ表示
  - 楽曲: Apple Music / Spotify の再生ボタンは URL がある場合のみ表示
  - センター楽曲: 王冠アイコン + "CENTER" バッジ

- **ペンライトカラー表のフィルタ**:
  - `hideGraduates`: 初期値 true（卒業メンバー非表示）
  - `query`: 名前検索（name / kana で部分一致）
  - 期生グループヘッダー: `currentGen === 'all'` の場合のみ表示

- **推し設定の排他制御**:
  - level 7-9 は各1名のみ。同レベルに別メンバーを設定すると既存が解除される
  - 解除時はトースト通知「XXX の推しランクが解除されました」

## 4. スタイル・デザインルール

- **テーマカラー**: `$themePrimaryHex` を CSS 変数 `--hinata-theme` として適用。フィルタボタンのアクティブ色に使用
- **フォントファミリー**: `'Inter', 'Noto Sans JP', sans-serif`
- **カードUI**: `bg-white border border-sky-50 rounded-2xl shadow-sm` を基本とする
- **サイドバー**: デスクトップ 240px 固定、モバイルはオフキャンバス (transform + z-index)
- **テーブルのスティッキー列**: メンバー管理の一覧編集で ID 列と名前列を `position: sticky` で固定
- **ペンライトカラーチップ**: `border-radius: 12px; box-shadow: 0 1px 2px rgba(15, 23, 42, 0.18)` で背景色に応じたテキスト色を動的計算（輝度判定）
- **画像表示**: メンバー画像は `object-cover` を基本とし、アー写のみ `object-cover object-top` で頭が切れないよう配慮
- **レスポンシブ**:
  - カードグリッド: 2列 (sm:3, lg:4, xl:5)
  - メンバー管理: 1カラム → lg で 3カラム分割
  - 推し設定メンバーグリッド: 4列 (sm:5, md:6, lg:8)
