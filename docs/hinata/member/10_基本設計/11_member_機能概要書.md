# メンバー (Member) 機能概要書

## 1. 目的と背景
- 日向坂46ポータル (Hinata) において、メンバー情報の閲覧・管理・推し活動を一元的に行える基盤を提供する。
- ライブ参加時のペンライト色確認、推しメンバーの最新情報追跡、管理者によるメンバーマスタ管理など、ファン活動に必要な情報をすべて Hinata ポータル内で完結させる。

## 2. 解決するペインポイント（課題）
- メンバーの基本情報（名前・期生・サイリウムカラー等）が一箇所にまとまっておらず、公式サイトや SNS を往復する必要がある。
- ライブ初心者がメンバーのペンライトカラーを即座に確認できる手段がない。
- 推しメンバーの最新動画・ブログ・ニュース・イベントを横断的に追跡する仕組みがない。
- ミーグリ（ミート&グリート）前のネタ準備や、推し画像の管理がバラバラになりがち。

## 3. コアバリュー（主要な提供価値）
- **メンバー帳**: 全メンバーをカード / リスト表示し、期生フィルタ・ソート・卒業メンバー切り替えで快適に閲覧できる。
- **メンバー管理 (Admin)**: 管理者がメンバーの基本情報・画像・個人活動・PV動画を登録・更新できる。一覧編集モードで一括更新にも対応。
- **推し設定**: ユーザーが最推し / 2推し / 3推し / 気になるを設定し、推しメンバー専用ページで横断タイムライン・楽曲・動画・イベント・マイフォト・ミーグリネタを一画面で確認できる。
- **ペンライトカラー表**: 初心者向けに全メンバーのサイリウムカラーを一覧表示。最新シングルのアー写付き。

## 4. スコープ
- 対象ユーザー:
  - **閲覧機能**: ログインユーザー全般（`Auth::requireLogin()`）
  - **管理機能**: `admin` または `hinata_admin` ロール保持者のみ（`HinataAuth::requireHinataAdmin()`）
- 関連する主要システム/外部API:
  - YouTube（紹介動画の埋め込み、メディア管理テーブル経由）
  - Apple Music / Spotify（楽曲の埋め込み再生リンク）
- サブドメイン構成:
  - **メンバー管理 (MemberController)**: メンバー帳、詳細API、管理画面、メンバー情報保存、画像アップロード、個人活動CRUD
  - **推し機能 (OshiController)**: 推し設定、推しメンバー個別ページ、推しデータAPI、推しタイムラインAPI
  - **ペンライト (PenlightController)**: ペンライトカラー一覧表示
- 非スコープ:
  - 楽曲管理 (Song / Release) の詳細仕様（別ドメイン設計書で扱う）
  - メディア管理 (MediaAsset) のアセット登録フロー自体（member ドメインでは参照のみ）
  - ミーグリネタ帳の全体管理仕様（TalkController として別ドメイン設計書で扱う）
