# タスク管理 UI設計書

## 1. 画面構成・レイアウト

### タスク管理メイン画面 (`private/apps/TaskManager/Views/index.php`)

本機能は単一画面内で4つのビューモードを切り替えるSPA的構成を採る。

- **構成要素**:
  - 共通サイドバー (`private/components/sidebar.php`)
  - ヘッダー領域（アプリアイコン、タイトル「タスク管理」、現在日付表示）
  - ビューモードタブバー（リスト / ボード / ガントチャート / カレンダー）
  - モバイル用クイック追加トグルボタン
  - クイック追加フォーム（優先度・カテゴリ・開始日・期限・タスク名）
  - 統計サマリバー（総件数・ステータス別件数・超過件数・完了率プログレスバー）
  - 検索・フィルタ領域（テキスト検索・カテゴリフィルタ・優先度フィルタ）
  - ソート・表示切替領域（ソート順選択・完了済み表示トグル・日向坂イベント表示トグル）
  - コンテンツ領域（選択中モードに応じた表示）
  - タスク詳細/編集モーダル（右からスライドイン）

### リストビュー (`#mode-list`)
- タスクを行カード形式で縦に並べる
- 各行: 優先度マーク、タスク名、カテゴリバッジ、ステータスバッジ、期限バッジ、チェックボックス
- カテゴリ順ソート時はカテゴリヘッダーでグルーピング
- 左ボーダーにカテゴリカラーを適用

### ボードビュー (`#mode-board`)
- 4列のカンバンレイアウト（未着手 / 進行中 / 保留 / 完了）
- 各列に件数表示とカラーテーマ（青 / 橙 / グレー / 緑）
- SortableJS によりカード間のドラッグ&ドロップが可能
- カードは小型で、タスク名・優先度・カテゴリ名・期限バッジを表示

### ガントチャートビュー (`#mode-gantt`)
- 左固定列にタスク名、右側に日付軸のバーを描画
- 開始日〜期日間をカテゴリカラーのバーで表示、バー内に日数表示
- 当日列は黄色ハイライト
- 横スクロール対応

### カレンダービュー (`#mode-calendar`)
- FullCalendar (dayGridMonth) による月表示
- タスクはカテゴリカラーで表示
- 日向坂イベントは水色（`#0ea5e9`）で表示、トグルで表示/非表示切替

### タスク詳細/編集モーダル (`#modalPanel`)
- 右からスライドインするパネル（最大幅480px）
- オーバーレイ背景（半透明黒 + ブラー）
- 入力項目: タスク名、説明、ステータス、優先度、カテゴリ（名前+色）、開始日、期限
- メタ情報: 作成日時、更新日時
- アクション: 削除ボタン（左下）、キャンセル/保存ボタン（右下）
- Escapeキーで閉じる

## 2. 共通コンポーネントの利用
- `private/components/sidebar.php`: 全画面共通のナビゲーションサイドバー。セッションのappsツリーからメニュー描画
- `private/components/theme_from_session.php`: `$appKey = 'task_manager'` でセッションからテーマカラーを取得。CSS変数 `--task-theme` に反映
- `private/components/head_favicon.php`: ファビコンと共通CSS (`/assets/css/common.css`) の読み込み
- `www/assets/js/core.js`: `App.post()` による非同期API通信、`App.toast()` による操作結果通知、`App.calculateRemaining()` による残日数計算

## 3. 状態と表示制御 (State & Conditional Rendering)

### ビューモード切替
- JavaScript変数 `currentMode` で現在のビューを管理（初期値: `'list'`）
- タブバーの `switchMode()` 関数で `#mode-{list|board|gantt|calendar}` の表示/非表示を切替
- ソート選択はリストモードのみ表示
- 完了済みトグルはボードモード以外で表示
- 日向坂イベントトグルはカレンダーモードのみ表示

### 完了タスクの表示
- `showCompleted` フラグ（初期値: `false`）で制御
- `false` の場合、`getFilteredTasks()` が `status !== 'done'` でフィルタ（ボードモードは除外）
- 完了タスク行には `.row-done` クラスが付与され、`opacity: 0.4`、タイトルに `line-through`

### 期限バッジの表示
- `getDueDateInfo()` で残日数を計算し、状態に応じたバッジを表示:
  - 超過（`days < 0`）: 赤系バッジ `badge-overdue`、行背景を `bg-red-50/60` に変更
  - 本日期限（`days === 0`）: 橙系バッジ `badge-today`、行背景を `bg-orange-50/60` に変更
  - 3日以内（`days <= 3`）: 黄系バッジ `badge-soon`
  - 4日以上: バッジなし（日付のみ表示）
- 完了タスクにはバッジを表示しない

### 優先度の表示
- 値3: `!!!`（赤 `text-red-500`）
- 値2: `!!`（橙 `text-orange-400`）
- 値1: `!`（灰 `text-slate-300`）

### ステータスバッジ
- `todo`: 表示なし（デフォルト状態のため）
- `doing`: 「進行中」バッジ（橙系）
- `pending`: 「保留」バッジ（灰系）
- `done`: 表示なし（チェックマーク＋取り消し線で表現）

### 統計サマリバー
- 全タスク（`rawTasks`）を対象に集計（フィルタ非適用）
- 超過件数が0件の場合は超過表示を非表示
- プログレスバー: 完了率（緑）＋進行中率（橙）を横幅パーセントで表現

### カテゴリ自動補完
- `<datalist id="categoryList">` にPHP側で全カテゴリを出力
- クイック追加フォーム・モーダルの両方で利用

### モバイル対応
- 768px以下でサイドバーは固定配置＋スライドイン
- クイック追加フォームはデフォルト非表示、トグルボタンで展開/格納
- ボードは2列×2行のグリッド表示 (`grid-cols-2 md:grid-cols-4`)

## 4. スタイル・デザインルール
- **テーマカラー**: `$themePrimaryHex` を CSS変数 `--task-theme` に設定し、アクティブタブやクイック追加ボタンに適用
- **フォント**: `Inter` + `Noto Sans JP`、ベースサイズ 13px
- **カードUI**: `bg-white border border-slate-200 rounded-lg p-3 shadow-sm` をリスト行に使用
- **ボードカード**: `bg-white rounded-lg p-2.5 border border-slate-200` にカテゴリカラーの左ボーダー（4px）
- **モーダルパネル**: 右からスライドイン、`max-width: 480px`、`box-shadow: -8px 0 30px rgba(0,0,0,0.1)`
- **ドラッグ&ドロップ**: ゴースト（`sortable-ghost`）は `opacity: 0.4`、選択中（`sortable-chosen`）は大きめシャドウ
- **アニメーション**: サイドバー・モーダル・クイック追加に `cubic-bezier(0.4, 0, 0.2, 1)` のイージング
- **ボード列カラー**: 未着手=`bg-blue-50/50`、進行中=`bg-amber-50/50`、保留=`bg-slate-50`、完了=`bg-green-50/50`
