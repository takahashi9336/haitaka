# Focus Note（フォーカスノート） 機能概要書

## 1. 目的と背景
- 鈴木祐氏（パレオな男）の著書『ヤバい集中力』に基づく「報酬感覚プランニング」をWeb上で実践できるようにする。
- 月単位（マンスリー）でターゲット設定・重要度チェック・具象イメージング・リバースプランニング・デイリータスク設定を行い、週単位（ウィークリー）でタスク絞り込み・障害対策・質問型アクション化までを一気通貫で管理する。
- さらに、科学的根拠に基づく目標設定手法（WOOP / MACの原則 / If-Thenプランニング）を組み込み、目標から行動への落とし込みを支援する。

## 2. 解決するペインポイント（課題）
- 紙のノートやメモアプリでは「報酬感覚プランニング」のフレームワークが維持しにくく、月→週→日の連携が途切れがちになる。
- 目標設定は抽象的になりがちで、具体的な行動に落とし込む仕組みが不足している。
- タスクの実施意図（いつ・どこで・何をするか）を明確化しないと、先延ばしが発生しやすい。

## 3. コアバリュー（主要な提供価値）
- **報酬感覚プランニングのデジタル化**: ターゲット→重要度チェック→具象イメージング→リバースプランニング→デイリータスクの5ステップを月次で実施可能。
- **週次タスク絞り込みと質問型アクション**: マンスリーで設定したデイリータスクから3〜5個を厳選し、「[名前]は、[時間]に[場所]で[タスク]をするか？」という実施意図文を自動生成して実行力を高める。
- **科学的目標設定**: WOOP（願望・成果・障害・計画）とMAC原則（測定可能・行動可能・適格性）に基づく目標・行動目標設定、If-Thenルールによる習慣化支援。
- **ダッシュボードによる今週のアクション管理**: 完了チェック・所要時間記録をワンタッチで操作可能。

## 4. スコープ
- 対象ユーザー: ログインユーザー（`Core\Auth::requireLogin()` 前提）
- 関連する主要システム/外部API: なし（外部API連携は不要、自己完結型機能）
- 対象機能
  - **ダッシュボード**: `/focus_note/index.php` - 今週のアクション一覧、各画面へのナビゲーション
  - **マンスリーページ**: `/focus_note/monthly.php` - 月次の報酬感覚プランニング（5ステップ）
  - **ウィークリーページ**: `/focus_note/weekly.php` - 週次のタスク選択・障害対策・質問型アクション設定
  - **目標設定の考え方**: `/focus_note/goal_setting.php` - MAC/WOOP/If-Thenの解説ページ
  - **目標・行動目標設定フォーム**: `/focus_note/goal_setting_form.php` - WOOP・行動目標・If-Thenルールの入力フォーム

## 6. 理論的背景
### 報酬感覚プランニング（マンスリー5ステップ）
1. **ターゲット**: 集中力が続かない作業の中で最も重要なものを1つ選定
2. **重要度チェック**: 達成しなければならない最大の理由を明確化
3. **具象イメージング**: ターゲットを具体的な映像イメージに変換
4. **リバースプランニング**: 達成した未来から逆算して短期目標を設定
5. **デイリータスク設定**: 毎日実行するタスクを一覧化

### WOOP（目標設定フレームワーク）
- Wish（願望）、Outcome（成果イメージ）、Obstacle（障害）、Plan（計画）、Being（ありたい姿）

### MACの原則（行動目標設定）
- Measurable（測定可能性）、Actionable（行動可能性）、Competent（適格性・能力向上）

### If-Thenプランニング
- 「もしAが起きたら、Bをする」形式での行動ルール化
