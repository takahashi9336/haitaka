# ユーザー設定（users_settings） 画面遷移図

## 1. 画面遷移フロー

本機能は単一画面（パスワード変更フォーム）とAPIエンドポイント群で構成される。画面遷移は最小限であり、主にサイドバーからのアクセスとAPI呼び出しが中心となる。

```mermaid
stateDiagram-v2
    [*] --> サイドバー : ログイン済み
    サイドバー --> 設定画面 : 設定アイコン押下

    state 設定画面 {
        [*] --> パスワード変更フォーム
        パスワード変更フォーム --> パスワード変更API : フォーム送信 (POST)
        パスワード変更API --> パスワード変更フォーム : 成功 → alert表示 + フォームリセット
        パスワード変更API --> パスワード変更フォーム : 失敗 → alert表示
    }

    state 管理画面_ユーザー管理 {
        [*] --> ユーザー一覧
        ユーザー一覧 --> ユーザー作成API : ユーザー追加ボタン → モーダル → POST
        ユーザー作成API --> ユーザー一覧 : 成功 → 画面リロード
        ユーザー一覧 --> パスワードリセットAPI : リセットボタン → モーダル → POST
        パスワードリセットAPI --> ユーザー一覧 : 成功 → alert表示
        ユーザー一覧 --> ロール変更API : ロール変更ボタン → モーダル → POST
        ロール変更API --> ユーザー一覧 : 成功 → 画面リロード
    }
```

## 2. 導線の補足
- **設定画面への導線**: 共通サイドバー（`private/components/sidebar.php`）のフッター部にある歯車アイコンから `/users_settings/` へ遷移する。全画面共通で表示される。
- **管理者向けAPI**: 管理画面（`/admin/users.php`）のUIから `/users_settings/api/` 配下のAPIを呼び出す構成。管理画面自体は別アプリ（Admin）の画面であり、本機能は API のみを提供する。
- **未ログイン時**: `Auth::requireLogin()` により `/login.php` へリダイレクトされる。
