# イベント管理・セットリスト・ライブガイド (event) UI設計書

## 1. 画面構成・レイアウト

### イベント一覧画面 (event_index.php)
- **構成要素**:
  - 共通サイドバー（`components/sidebar.php`）
  - ヘッダー（戻るボタン → Hinataポータル、カレンダーアイコン、タイトル「イベント」、ビューモード切替ボタン群、管理者のみ「管理」ボタン）
  - NEXT EVENT カウントダウンバナー（次のイベント名・日付・残日数）
  - カテゴリフィルタチップ（すべて/ライブ/ミーグリ/リアルMG/リリース/メディア/スペイベ/その他）
  - メインコンテンツ（4ビューモードにより切替）

- **カレンダー+リスト (calendar)**:
  - デスクトップ: 左に3ヶ月分のミニカレンダーサイドバー（`cal-sidebar` 幅340px）、右にイベントカードリスト
  - モバイル: 上部に折りたたみ式シングルカレンダー（スワイプ対応）、下にリスト
  - カレンダー日セルにイベントカテゴリ色のドット表示。選択日をハイライト（`bg-[#e0f2fe]`）
  - イベントカードはクリックで詳細パネル展開（`detail-panel`、max-height トランジション 0.35s）
  - 過去イベントは `opacity: 0.55`、ホバーで `0.85` に回復

- **タイムライン (timeline)**:
  - 中央に縦線（`tl-line`、幅2px）、交互配置のイベントカード（左右交互、モバイルは全て左寄せ）
  - 各カードにカテゴリ色のノード（`tl-node`、12px 丸）
  - TODAY マーカー（テーマカラーの水平線 + ラベル）
  - カードクリックでスライドパネル表示

- **ダッシュボード (dashboard)**:
  - 上段: 統計カード（カテゴリ別件数、次のイベント、月間件数）
  - 下段: 横スクロールイベントカード（`dash-scroll`、flex 横配列、各カード 260px 固定幅）
  - カードクリックでスライドパネル表示

- **マスタ・ディテール (master)**:
  - 左パネル: イベントリスト（`md-list` 幅340px、デスクトップ固定/モバイル全幅）
  - 右パネル: 選択イベントの詳細表示（`md-detail`、モバイルではスライドイン）
  - 選択行は `bg-[#eff6ff]` + テーマカラー左ボーダー

- **共通: イベント詳細パネル / スライドパネル**:
  - イベント名、日付、カテゴリバッジ、会場名、ステータスセレクト（参加/不参加/検討/当選/落選）
  - 座席情報・感想テキスト入力（保存ボタン付き）
  - 参戦トグルボタン（ライブイベントのみ表示）
  - YouTube 埋め込みプレイヤー（`video_key` がある場合）
  - セットリスト / 影ナレ / 初参戦ガイドへのリンク
  - 過去イベント無限スクロール領域（`past_events.php` API で追加ロード）

- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻るボタン → Hinataポータル/イベント一覧、カレンダーアイコン、タイトル「Event Admin」）

  - 各行: 日付ブロック（月/日、カテゴリ別グラデーション背景）、イベント名、カテゴリバッジ、会場名

### セットリスト編集画面 (setlist_edit.php)
- **構成要素**:
  - 共通サイドバー
  - ヘッダー（戻るボタン → セットリスト閲覧、「セットリスト編集」ラベル、イベント名、「一括インポート」「追加」「保存」ボタン）
  - 編集カード:
    - 行リスト（`#rows`、`space-y-2`）: 各行は動的に追加/削除/**並替（ドラッグ&ドロップ）**/**途中挿入**
    - 各行の入力要素:
      - ドラッグハンドル（行番号を兼ねる。ここを掴んでD&Dで並替。行はハンドルからのみドラッグ可）
      - 種別セレクト（曲/MC/ブロック）
      - アンコール区分セレクト（本編/EN/W EN、**全種別共通**。2026-08-09 に曲以外へも適用拡張）
      - 曲コンボボックス（種別=曲の場合のみ表示。テキスト入力欄＋リリース別グループ化ドロップダウンで、**部分一致による絞り込み検索**に対応。選択で hidden の `song_id` を確定）
      - センターメンバー（複数選択、期別 optgroup 付き、種別=曲の場合のみ。ダブルセンター対応）
      - ラベル入力（MC/ブロック時のみ表示。行にスコープした querySelector で取得）
      - ブロック種別セレクト（告知/ダンスセッション/セッション/その他、ブロック時のみ）
      - 削除ボタン
    - 行間インサーター: 行のホバー/フォーカス時に**行間の左端**に「＋」ボタンが出現し、その位置に新規行を挿入
    - ヘルプテキスト（「曲以外は曲数に含めない」「アンコール区分は曲/MC/ブロックいずれにも設定可」旨）
  - **一括インポート モーダル**（`#importModal`）:
    - TSV（タブ区切り・1行1エントリ）を貼り付けて解析し、フォーム行として一括反映（既存行を置き換え、DB保存は既存「保存」ボタンで確定＝プレビュー方式）
    - 列: `タイプ / 内容 / センター / 区分`。タイプ省略時は「曲」、区分省略時は「本編」。センターは「、」区切りで複数可
    - 曲名は完全一致優先＋部分一致で照合。未一致・複数該当の曲は未選択の行として追加し、レポート欄に確認事項を表示

## 3. 状態と表示制御 (State & Conditional Rendering)

### イベント一覧画面
- **ビューモード切替**: `switchViewMode('calendar'|'timeline'|'dashboard'|'master')` で4モード切替。アクティブボタンは `bg-[var(--hinata-theme)] text-white`、非アクティブは `color: #94a3b8`
- **カテゴリフィルタ**: `filter-chip` クリックで `.active` 切替。アクティブ時はカテゴリ色の背景 + 白文字
- **イベント詳細パネル展開**: カードクリックで `detail-panel.open` クラス付与、`max-height` 動的計算
- **ステータスセレクト**: `save_event_status.php` API でリアルタイム保存。値: 1=参加, 2=不参加, 3=検討, 4=当選, 5=落選, 0=クリア
- **参戦トグル**: ライブイベント（category=1）のみ表示。`toggle_attendance.php` API でトグル
- **過去イベント**: カード色 `event-card-past`（`opacity: 0.55`）。スクロール末端で `past_events.php` API を自動呼び出し（無限スクロール）
- **管理者ボタン**: `$user['role']` が `admin` または `hinata_admin` の場合のみ「管理」ボタン表示

### イベント管理画面
- **新規/編集/複製モード**: フォーム上部のモード表示。編集時は「変更を保存」「削除」ボタン表示、新規時は「保存」のみ
- **ミーグリ部数フィールド**: カテゴリ 2（ミーグリ）または 3（リアルMG）選択時のみ表示
- **関連リンク種別**: `EventRelatedLinkService::classifyKind()` と同等のクライアント側ロジックで自動判定。`manual_override` フラグで手動変更可能
- **ジオコーディングボタン**: 会場住所入力後にクリック可能。`geocode_event_place.php` API 呼び出し後、緯度/経度/place_id を表示・保存
- **系列マスタ管理**: 系列名テキスト入力（`datalist` で既存名を検索）。未登録名を入力してイベントを保存すると、フォーム送信時に `save_event_series.php` を先行呼び出しして系列を自動作成し、返却IDを `series_id` にセットしてからイベントを保存する（2026-08-09 バグ修正: 従来は未登録名を入力しても系列が保存されず「系列なし」で登録されていた）。「削除」ボタンで削除確認、参照 > 0 件の系列は削除不可
- **最近の編集リストタブ**: フィルタ値 `live`/`mg`/`other` で行の `data-filter` を照合しフィルタ

### セットリスト閲覧画面
- **空セットリスト**: 「未登録です。」メッセージ表示
- **ナンバリング**: 番号は**楽曲行のみ**に採番（MC/ブロック行には番号を振らない。2026-08-09 変更、従来は全行通し番号）
- **行種別アイコン**: 各行の左端にタイプ別アイコンを表示（曲=音符〔スカイ〕/ MC=マイク〔アンバー〕/ ブロック=レイヤー〔バイオレット〕）。MC/ブロック行は薄背景 + 種別を色付きタグで表示
- **リリース名表示位置**: 楽曲のリリース（シングル/アルバム）名を**曲名のすぐ右**に小さく表示（従来は行右端）。センター表示は右端へ
- **アンコール区切り**: `encore` 値の変化を検知し ENCORE / W ENCORE ラベル行を自動挿入。**全行（曲/MC/ブロック）の encore を対象**に判定（2026-08-09 変更、従来は曲行のみ）
- **ブロック種別表示**: `block_kind` を内部キーではなく日本語ラベル（告知/ダンスセッション/セッション/その他）へマッピングして表示（`$blockKindLabels`。2026-08-09 バグ修正、従来は "other" 等の内部キーがそのまま表示）
- **センター表示**: `center_members` 配列（hn_setlist_centers を正）から表示。フォールバックとして `center_member_name`（レガシー）も参照
- **管理者ボタン**: `$user['role']` が `admin` / `hinata_admin` の場合のみ「編集」ボタン表示

### セットリスト編集画面
- **行種別切替**: 種別セレクト変更で曲コンボボックス/ラベル入力/ブロック種別の表示切替
- **曲検索コンボボックス**: テキスト入力での部分一致絞り込み。フォーカス外し時に表示テキストと hidden `song_id` を整合（完全一致で確定、非一致は選択済みの曲名へ復帰またはクリア）
- **並替（ドラッグ&ドロップ）**: ドラッグハンドルからのみドラッグ開始。ドロップ先行をハイライト表示し、`renumber()` で番号を振り直し
- **途中挿入**: 行ホバー/フォーカスで行間左端に「＋」ボタンが出現、`insertRowAfter()` で直下に新規行挿入
- **アンコール区分**: 曲/MC/ブロックの全種別で選択可能（2026-08-09 拡張。`collect()` は全種別で encore を収集、`SetlistModel::saveForEvent()` は entry_type を問わず保持）
- **ラベル取得のスコープ**: MC/ブロックはいずれも `.setlist-label-input` を持つため、`.row-mc` / `.row-block` にスコープして取得（2026-08-09 バグ修正、従来はブロックのラベルが MC 側の空入力欄を拾い保存されなかった）
- **センター複数選択**: 複数メンバー選択可能（ダブルセンター対応）。期別 optgroup で視認性確保
- **一括インポート（TSV）**: 「一括インポート」ボタンからモーダルを開き、TSV を貼り付けて `parseSetlistTsv()` で解析→フォームへ反映（既存置き換え、プレビュー方式）。列は `タイプ / 内容 / センター / 区分`、曲は完全一致優先＋部分一致で照合し未一致はレポート表示

### ライブガイド閲覧画面
- **イベント未選択時**: ガイドコンテンツ非表示（`#guideContent.hidden`）
- **イベント選択後**: `get_live_guide.php` API でデータ取得、DOM 生成
- **ミニプレイヤー**: 曲行の Spotify/Apple Music ボタンクリックで `#songMiniPlayer` を表示。同じ曲の再クリックで閉じる
- **コラボ・ハッシュタグセクション**: データがある場合のみ `.hidden` を解除して表示
- **動画モーダル**: サムネイルクリックで `video_modal.php` の共通モーダルを開く

### ライブガイド楽曲管理画面
- **イベント未選択時**: ガイドコンテンツ非表示
- **楽曲検索フィルタ**: `#searchSong` 入力で `.release-group` / `.song-row` を動的表示/非表示
- **確度変更**: 登録済み曲の `.lik-select` 変更で即時グループ内のデータ更新
- **保存**: `collectItems()` で全候補曲の `song_id` / `likelihood` / `sort_order` を収集し、`save_event_guide_songs.php` API へ POST

## 4. スタイル・デザインルール
- **テーマカラー**: `$themePrimaryHex` を CSS 変数 `--hinata-theme` に設定。ビューモードのアクティブ状態、ボタン背景、フォーカスリングに使用
- **フォント**: `'Inter', 'Noto Sans JP', sans-serif`
- **カードUI**: `bg-white rounded-2xl border border-slate-100 shadow-sm`（セクションカード）
- **カテゴリカラー**: ライブ=#3b82f6, ミーグリ=#10b981, リアルMG=#f59e0b, リリース=#8b5cf6, メディア=#ec4899, スペイベ=#f97316, その他=#64748b
- **サイドバー**: デスクトップ固定 240px、モバイルはハンバーガーメニューによるスライドイン（`transform: translateX(-100%)` → `translateX(0)`）
- **スライドパネル**: 幅 90%（max 480px）、右からスライドイン。背景オーバーレイ `rgba(0,0,0,0.3)`
- **過去イベント**: `opacity: 0.55`、ホバーで `0.85`
- **ビューモード切替ボタン**: 32px 角丸8px、`bg-slate-100` コンテナ内、アクティブ時テーマカラー背景 + 白アイコン + `box-shadow`
- **レスポンシブブレークポイント**: 768px（モバイル↔デスクトップ）、1024px（マスタ・ディテールの詳細パネル切替）
