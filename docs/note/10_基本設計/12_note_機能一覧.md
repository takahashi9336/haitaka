# メモ（Note） 機能一覧

## 1. 画面一覧
| 画面名 (論理名) | ファイルパス | 概要 |
| :--- | :--- | :--- |
| メモ管理画面 | `www/note/index.php` | 汎用メモとリストエントリの一覧表示・管理を行うメイン画面。クイックメモ追加、タブ切替（汎用メモ/リスト）、アクティブ/アーカイブ切替を提供する |
| メモ詳細モーダル | `private/apps/Note/Views/note_index.php` 内 `#detailModal` | メモカードクリック時にオーバーレイ表示される編集モーダル。タイトル・本文の編集、ピン留め・背景色変更・アーカイブ・削除を実行する |
| リスト詳細モーダル | `private/apps/Note/Views/note_index.php` 内 `#listDetailModal` | リストエントリのクリック時にオーバーレイ表示される編集モーダル。種別に応じた入力フォームを動的に生成し、保存・ピン留め・背景色変更・アーカイブ・削除を実行する |

## 2. 機能・アクション一覧
| 機能名 | 種類 (画面/API/Batch) | 概要 |
| :--- | :--- | :--- |
| メモ一覧表示 | 画面 | ログインユーザーのアクティブ/アーカイブメモをカラムレイアウトのカードグリッドで表示する（ピン留め優先・作成日時降順） |
| クイックメモ追加 | 画面/処理 | タイトル（任意）と本文を入力し、新規メモを即座に保存する。タイトル未入力時は本文先頭30文字を自動設定する |
| メモ保存 API | API (POST/JSON) | 新規メモを `nt_notes` に INSERT する |
| メモ更新 API | API (POST/JSON) | 既存メモのタイトル・本文・背景色・ピン留め・ステータスを部分更新する |
| メモ削除 API | API (POST/JSON) | 指定メモを `nt_notes` から物理削除する |
| メモピン留めトグル API | API (POST/JSON) | 指定メモの `is_pinned` を 0/1 で反転する |
| メモアーカイブ | 画面/処理 | メモの `status` を `archived` に更新し、アクティブ一覧から除外する |
| メモ復元 | 画面/処理 | アーカイブ済みメモの `status` を `active` に戻す |
| メモ背景色変更 | 画面/処理 | 詳細モーダル内のインラインカラーピッカーで10色から選択し、即座にAPIで更新する |
| 主タブ切替 | 画面 | 汎用メモタブとリストタブを切り替え、対応するセクションの表示/非表示を制御する |
| サブタブ切替 | 画面 | アクティブ/アーカイブタブを切り替え、表示するメモまたはリストのフィルタを変更する |
| リスト種別チップ切替 | 画面 | 6種別（やること/疑問・仮説/はじめて/おもろかったこと/書籍メモ/汎用リスト）をチップボタンで切り替え、対応するエントリ一覧を表示する |
| リストエントリ新規追加 | 画面/処理 | 選択中の種別に応じたモーダルフォームを開き、新規エントリを保存する |
| リストエントリ保存 API | API (POST/JSON) | 新規リストエントリを `nt_list_entries` に INSERT する。payload は `normalizePayload()` でバリデーション・正規化される |
| リストエントリ更新 API | API (POST/JSON) | 既存リストエントリの payload・背景色・ピン留め・ステータスを部分更新する |
| リストエントリ削除 API | API (POST/JSON) | 指定リストエントリを `nt_list_entries` から物理削除する |
| リストエントリピン留めトグル API | API (POST/JSON) | 指定リストエントリの `is_pinned` を 0/1 で反転する |
| リストアーカイブ/復元 | 画面/処理 | リストエントリの `status` を `archived`/`active` に変更する |
| URLパラメータによる直接遷移 | 画面 | `/note?tab=list&kind=todo` の形式でリストタブと種別を指定して直接開くことができる |

## 3. 関連テーブル一覧
| テーブル物理名 | テーブル論理名 | 役割（CRUDの種別など） |
| :--- | :--- | :--- |
| `nt_notes` | メモ | メインテーブル。汎用テキストメモの保存 (CRUD すべて) |
| `nt_list_entries` | リストエントリ | リスト種別エントリの保存。JSON payload で種別ごとのデータを格納 (CRUD すべて) |
